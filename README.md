# PTR · Русская вики

**Сайт: https://noxdregon.github.io/ptr-wiki-ru/**

Неофициальная русскоязычная библиотека Pokémon Tabletop Reunited 1e.

## Что есть в вики

- 70 классов тренеров с источниками и переключением обычной версии / Class Reworks.
- Покедекс: поиск по русскому и английскому названию, национальному номеру, типам и источникам.
- 1806 записей видов и форм, включая 1198 записей основного покедекса.
- 1294 приёма и 631 способность; приёмы и способности открываются отдельными карточками.
- Основные правила, плейтесты, предметы и черты.
- Локальное избранное и светлая / тёмная тема.

## Размещение и обновление

Это самостоятельная статическая копия сайта. HTML, CSS, JavaScript и data.json находятся в этом репозитории; работа сайта не требует хостинга chatgpt.site.

GitHub Pages публикует корень ветки main. Для обновления измените файлы и создайте коммит. Файл .nojekyll отключает обработку Jekyll.

Изображения покемонов и шрифты загружаются из внешних источников. Избранное и настройки сохраняются отдельно для каждого адреса сайта.

## Источники и перевод

Первоисточники, версия компендиумов и происхождение классов указаны внутри вики в разделе «Источники и перевод». Контрольные суммы перенесённых файлов сохранены в SOURCE_SNAPSHOT.json.

Большая часть перевода машинная и требует редакторской вычитки. Обе страницы Cheerleader вычитаны вручную. Английские названия сохранены для поиска в Foundry.

Pokémon, названия и изображения персонажей принадлежат Nintendo, Creatures и GAME FREAK. Проект не связан с правообладателями или разработчиками PTR. Для русских названий покемонов из sindresorhus/pokemon сохранена MIT-лицензия в names-LICENSE.txt.
